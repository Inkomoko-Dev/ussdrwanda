Inkomoko USSD simulator

Same session rules as the sample gateway: Dial opens a new session, each Send continues it with the latest reply, and a closed session cannot be resumed. The request is the FDI JSON body for /api/ussd.

  • Mock numbers: 250788000001 (one active loan), 250788000002 (several loans), 250722000003 (Airtel).
  • Replies are 0–9, * and #. On the main menu, 0 exits. Inside a service, 00 goes back.
